# 08 Lifetimes

lifetime注釈は、参照を「長生きさせる」ものではありません。
**「この参照とあの参照の関係」をコンパイラに伝える宣言**です。値の生存期間は、注釈を書いても1秒も変わりません。

## この章の到達目標

- lifetime注釈が「何を主張しているのか」を、関数のシグネチャから読み取れる
- 構造体に参照を持たせるか、所有させるかを判断できる
- 構造体のメソッドの戻り値を、`&self` と構造体の `'a` のどちらに結びつけるべきか判断できる
- lifetime省略規則と、`'static` にまつわる誤解（`T: 'static` は「永遠に生きる」ではない）を説明できる
- `for<'a>`（HRTB）が必要になる理由を、最小限の例で説明できる
