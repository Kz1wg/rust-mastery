# 14 Macros

`println!` や `vec!` のように、名前の後ろに `!` が付くものがマクロです。
マクロは「コードを書くコード」で、**コンパイルの前に、別のコードへ展開されます**。

強力な道具ですが、この章で一番伝えたいのは次のことです。

> **関数・ジェネリクス・trait で書けるなら、マクロは使わない。**

マクロは読みにくく、エラーメッセージも分かりにくくなります。
「それでもマクロでなければ書けない」場面を見分けられるようになるのが、この章の目標です。

## この章の到達目標

- 関数では書けず、マクロが必要になる場面を説明できる
- `macro_rules!` で簡単なマクロを書き、その限界（式の二重評価など）を説明できる
- procedural macro（特に derive）が「コードを受け取ってコードを返す関数」であることを説明できる
