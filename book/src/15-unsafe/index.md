# 15 Unsafe Rust

`unsafe` は「安全でないコードを書いてよい」という許可ではありません。
**「ここではコンパイラが安全性を確認できないので、代わりに私が確認しました」という宣言**です。

この章の目標は、unsafe なコードを積極的に書けるようになることではありません。

- unsafe が**何を宣言しているのか**を理解する
- unsafe を**小さく閉じ込めて、外からは安全に使える形**にする考え方を知る
- C 言語との境界（FFI）で、何に気を付けるべきかを知る

ことです。

## この章の到達目標

- `unsafe` で「できるようになること」と「できるようにならないこと」を説明できる
- unsafe を内側に閉じ込めた安全なAPI（safe abstraction）を作れる
- `// SAFETY:` コメントや `# Safety` ドキュメントで、守るべき条件を書ける
- FFI で C の関数を呼び、文字列を安全に受け渡しできる
