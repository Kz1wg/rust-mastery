# P2: 小さな CSV パーサ

## 何を作るか

CSV（カンマ区切りのテキスト）を読み込み、1行ずつレコードとして取り出すライブラリです。

```text
name,city,score
alice,"Tokyo, JP",90
bob,Osaka,85
```

```rust,ignore
let reader = CsvReader::new(input)?;
for record in reader {
    let record = record?;
    println!("{} は {}", record.get("name").unwrap(), record.get("city").unwrap());
}
```

対応する形式は、次のように**範囲を絞っています**。

| 対応すること | 例 |
| --- | --- |
| カンマで区切る | `a,b,c` → `a` / `b` / `c` |
| `"` で囲むと、中にカンマを書ける | `"Tokyo, JP"` → `Tokyo, JP` |
| 囲んだ中の `""` は、`"` 1文字 | `"say ""hi"""` → `say "hi"` |
| 空行は読み飛ばす | |

| 対応しないこと | 理由 |
| --- | --- |
| 引用符の中の改行（1つのフィールドが複数行にまたがる） | 1行 = 1レコードという前提が崩れ、実装が大きくなるため |

実務では `csv` crate を使います。このプロジェクトの目的は、**自分でパーサを書くことで、状態機械とエラー設計を組み合わせる**ことです。

## 設計の問い

> **問い1**: 1行を解析するとき、`if` を重ねて書くのではなく、状態機械にしているのはなぜでしょうか。

<details>
<summary>考え方の例</summary>

CSV の1文字の意味は、**それまでに何を読んだか**で変わります。
同じ `,` でも、引用符の外なら「区切り」、引用符の中なら「ただの文字」です。
同じ `"` でも、フィールドの始まりなら「囲みの開始」、囲みの中なら「閉じか、`""` の1文字目」です。

「今どこにいるか」を `State` enum で持っておくと、**状態 × 読んだ文字**の組み合わせを `match` で全部書き出せます。
`src/lib.rs` の `parse_line` のドキュメントにある表が、そのまま `match` の腕になります。
書き忘れた組み合わせがあれば、`match` の網羅性チェック（Lesson 02-1）がコンパイルエラーで教えてくれます。

</details>

> **問い2**: `Record` はヘッダーを `Rc<Vec<String>>` で持っています。`Vec<String>` をそのまま持つのと比べて、何が良いのでしょうか。

<details>
<summary>考え方の例</summary>

ヘッダーはどのレコードでも同じです。`Vec<String>` をそのまま持つと、**レコードを1件作るたびにヘッダーをまるごとコピー**することになります。
1万行の CSV なら、同じヘッダーを1万回コピーします。

`Rc` で包むと、各レコードは「同じヘッダーを指すポインタ」を持つだけで済みます（`Rc::clone` は参照カウントを1増やすだけで、中身はコピーしません）。

別の選択肢として、`Record<'a>` のように**ヘッダーへの参照**を持たせる方法もあります（Chapter 08）。
ただしそうすると、レコードが `CsvReader` より長く生きられなくなり、「読み終わった後にレコードだけ取っておく」使い方ができません。
`Rc` はその制約を避けつつ、コピーも避ける選択です。

</details>

> **問い3**: エラーに行番号を入れるとき、空行を読み飛ばす処理と、どう関係しますか。

<details>
<summary>考え方の例</summary>

利用者がエラーを見てファイルを開いたとき、**エディタに表示される行番号**と一致していないと困ります。
空行を読み飛ばしても、行番号は「ファイルの何行目か」を数え続ける必要があります。
「読み飛ばしたレコードの数」ではなく「読んだ行の数」を数える、ということです。
テストの `field_count_mismatch_reports_the_real_line_number` が、ちょうどこれを確かめています。

</details>

## 進め方

1. **`parse_line`**: ドキュメントの表を見ながら、`match (state, c)` を書く。まず `simple_fields` のテストを通し、次に引用符、エラーの順に広げる
2. **`Record::get`**: ヘッダーの中で名前の位置を探し、同じ位置の値を返す（`position` を使う）
3. **`CsvReader::next`**: 空行を飛ばし、`parse_line` を呼び、フィールドの数を確かめる
